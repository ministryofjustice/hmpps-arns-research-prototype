SAN research storyboard

Screen-by-screen journeys for the active SAN research sections. Use the tabs to switch section.

For Miro, drag the matching folder under images onto a board — filenames sort in journey order. Print to PDF if you want a single file to share (print includes every section).

AccommodationEmployment and educationFinancesDrug use

Filled answers so summaries and conditionals match a real assessment. Temporary accommodation uses the same details questions as settled in this prototype, so it is not a separate row.

Routes

  1. Somewhere to live → Is it settled? Yes
  2. Somewhere to live → Details (no accommodation) No
  3. Is it settled? → Details (location and suitability) Yes or no
  4. Details → Concerns Location no, or suitability concerns
  5. Details → Summary No concerns, or no accommodation
  6. Concerns → Summary
  7. Summary → Practitioner analysis

Income from family or friends opens the over-reliant page. Further assessment “yes” splits money management, debt and changes onto their own pages. Own debt adds a debt types page.

Routes

  1. Income → Over-reliant on family? Income includes family
  2. Income → Further assessment? No family income
  3. Over-reliant on family? → Further assessment?
  4. Further assessment? → Summary No
  5. Further assessment? → Money management Yes
  6. Money management → Debt
  7. Debt → Debt types Own debt
  8. Debt → Changes No own debt
  9. Debt types → Changes
  10. Changes → Summary
  11. Summary → Practitioner analysis

No drug use goes to summary. Yes then types, when last used, use before custody, optional injected-when, then background. Injected-when only appears if an injectable drug was injected.

Routes

  1. Ever used drugs? → Summary No
  2. Ever used drugs? → Which drugs? Yes
  3. Which drugs? → When last used
  4. When last used → Before custody
  5. Before custody → When injected Injected an injectable drug
  6. Before custody → Background Did not inject
  7. When injected → Background
  8. Background → Summary
  9. Summary → Practitioner analysis
