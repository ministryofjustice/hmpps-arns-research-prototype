SAN research storyboard

Screen-by-screen journeys for accommodation, employment and education, finances and drug use.

For Miro, open storyboards/san-research/images and drag a section folder onto the board. Filenames sort in journey order, so the screens land in step sequence. You can also copy the PNGs and paste them straight onto a frame.

AccommodationEmployment and educationFinancesDrug use

Settled accommodation asks location, then suitability. A concern page follows only when the answer needs it. No accommodation skips settled and both concern pages, and asks why there is no accommodation and about changes on the same page.

Routes

  1. Somewhere to live → Is it settled? Yes
  2. Somewhere to live → Why no accommodation, and changes No. Both questions on one page
  3. Location is not suitable → Location concerns
  4. Suitability concerns, or not suitable → Suitability concerns
  5. No concerns → Changes Location yes and suitability yes
  6. Changes → Summary

Employed or self-employed goes straight to details, including employment history. Unemployed asks if Alex has been employed before. Never employed hides employment history. These journeys select no reading, writing or numeracy difficulties, so the difficulty page is skipped.

Routes

  1. Employment status → Details Employed, self-employed or retired
  2. Employment status → Employed before? Unemployed or unavailable
  3. Employed before? → Details Yes or no
  4. Details → How much difficulty? Reading, writing or numeracy selected
  5. Details → Summary No difficulties

Income from family or friends opens the over-reliant page. Yes on that page skips the further assessment question and goes straight to money management. No or unknown still asks further assessment. Own debt adds a debt types page.

Routes

  1. Income → Over-reliant on family? Income includes family or friends
  2. Income → Further assessment? No family income
  3. Over-reliant on family? → Money management Yes
  4. Over-reliant on family? → Further assessment? No or unknown
  5. Further assessment? → Summary No
  6. Further assessment? → Money management Yes
  7. Debt → Debt types Own debt
  8. Debt types or no own debt → Changes, then summary

No drug use goes to summary. Yes then asks which drugs, when they were last used, and background. The injected-when page appears only if an injectable drug was injected.

Routes

  1. Ever used drugs? → Summary No
  2. Ever used drugs? → Which drugs? Yes
  3. When last used → Background
  4. Background → When injected Injected an injectable drug
  5. Background → Summary Did not inject, or the drug is not injectable
