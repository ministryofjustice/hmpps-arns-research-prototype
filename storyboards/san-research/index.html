SAN research storyboard

Screen-by-screen journeys for each SAN research section. Each journey is a main route, with one screenshot per step.

For Miro, open storyboards/san-research/images and drag a section folder onto the board. Filenames sort in journey order, so the screens land in step sequence. You can also copy the PNGs and paste them straight onto a frame.

Settled accommodation asks location, then suitability. A concern page follows only when the answer needs it. No accommodation skips settled and both concern pages. Changes is always its own page, including when there is no accommodation.

Routes

  1. Somewhere to live → Is it settled? Yes
  2. Somewhere to live → Why no accommodation? No
  3. Location is not suitable → Location concerns
  4. Suitability concerns, or not suitable → Suitability concerns
  5. No concerns → Changes Location yes and suitability yes
  6. Changes → Summary

Employed or self-employed goes straight to details, including employment history. Unemployed asks if Alex has been employed before. Never employed hides employment history. Routes

  1. Employment status → Details Employed, self-employed or retired
  2. Employment status → Employed before? Unemployed or unavailable
  3. Retired → Details without skills for work
  4. Details → How much support? Reading, writing or numeracy selected
  5. Details or support → Changes No support needed, or after the support page
  6. Changes → Summary

No drug use goes to summary. Yes asks which drugs, when they were last used, then the same frequency questions for drugs used and not used in the last 6 months. Injecting opens a timing page. Help to stop or reduce is its own page: present tense for the last 6 months, past tense for earlier use. Changes follows.

Routes

  1. Ever used drugs? → Summary No
  2. Ever used drugs? → Which drugs? Yes
  3. When last used → Frequency for recent and older drugs
  4. Injected an injectable drug → When injected
  5. Last 6 months → Does anything help them stop or reduce?
  6. More than 6 months ago only → Has anything helped in the past?
  7. Help → Changes, then summary

The journey starts with current issues. Current issues ask about binge or excessive use, then what helps them stop or reduce, in the present tense. No current issues asks about past issues. Past issues only uses the past-tense help question. Never drunk, or no current and no past issues, goes straight to the summary.

Routes

  1. Current issues → Binge or excessive use Significant or some issues
  2. Binge or excessive use → Does anything help them stop or reduce?
  3. No current issues → Any past issues?
  4. Past issues → Has anything helped in the past?
  5. Never drunk, or no past issues → Summary No practitioner analysis when they have never drunk
  6. Help → Changes, then summary
