SAN research — Accommodation

Filled answers so summaries and conditionals match a real assessment. Temporary accommodation uses the same details questions as settled in this prototype, so it is not a separate row.

Open this file in a browser. For Miro, drag the images folder onto a board — filenames sort in journey order. Print to PDF if you want a single file to share.

Routes

  1. Somewhere to live → Is it settled? Yes
  2. Somewhere to live → Details (no accommodation) No
  3. Is it settled? → Details (location and suitability) Yes or no
  4. Details → Concerns Location no, or suitability concerns
  5. Details → Summary No concerns, or no accommodation
  6. Concerns → Summary
  7. Summary → Practitioner analysis
